# 04 · פיצ'רים ומוצר

איפיון פונקציונלי של היכולות. מסומן **[MVP]** למה שנכנס לגרסה הראשונה, ו-**[V1+]**
להמשך. לב-ה-AI מפורט בנפרד ב-[פרק 05](05-ai-dunning-engine.md).

## 4.1 ייבוא וניהול חשבוניות
- **[MVP]** ייבוא **CSV** + הזנה ידנית של חשבונית (לקוח, סכום, תאריך-הנפקה,
  תאריך-יעד, סטטוס, פרטי-קשר).
- **[MVP]** רשימת-חשבוניות מרכזית עם סינון (פתוח/באיחור/שולם/במחלוקת).
- **[V1+]** אינטגרציה דו-כיוונית ל-**QuickBooks / Xero** (סנכרון אוטומטי של
  חשבוניות וסטטוס-תשלום), ובהמשך חשבונית-ישראלית/Green Invoice.

## 4.2 מנוע-הרצף (Cadence Engine)
- **[MVP]** רצף-תזכורות מוגדר לאורך זמן: לפני-יעד (תזכורת-נחמדה), ביום-היעד,
  ואחרי-יעד בהסלמה הדרגתית (+3, +7, +14, +30 יום).
- **[MVP]** טמפלייטים חכמים כברירת-מחדל + עריכה/אישור ע"י המשתמש.
- **[MVP]** **AI מנסח** כל הודעה מותאמת (ראו פרק 05), לא טקסט קבוע.
- **[V1+]** רצפים שונים פר-סגמנט-לקוח (לקוח-טוב מול חייב-כרוני) ופר-ורטיקל.

## 4.3 ערוצי-שליחה
- **[MVP]** **אימייל** (שליחה מהדומיין של המשתמש דרך ספק, עם reply-to שלו).
- **[V1+]** **SMS** ו-**WhatsApp** (עם ניהול הסכמות/opt-in — ראו [תאימות](10-roadmap-risks-compliance.md)).
- **[V1+]** בחירת-ערוץ אוטומטית לפי מה שעובד ללקוח.

## 4.4 תשלום
- **[MVP]** **לינק-תשלום** מוטמע בכל תזכורת (Stripe Payment Link / Pay-link),
  שמסמן את החשבונית כ"שולם" אוטומטית עם קבלת-התשלום.
- **[V1+]** תשלום-חלקי, תוכנית-תשלומים, וריבוי-מטבעות.

## 4.5 Dashboard ודיווח
- **[MVP]** **Aging report** (0–30 / 31–60 / 61–90 / 90+), סך-כסף-פתוח, וסטטוס
  לכל חשבונית.
- **[MVP]** **דוח-השפעה:** כמה נגבה, כמה DSO ירד, זמן-ממוצע-עד-תשלום — ההוכחה
  שהמוצר עובד (וגם הבסיס ל-success-fee).
- **[V1+]** תחזית-תזרים, תובנות פר-לקוח ("מי משלם מאוחר תמיד").

## 4.6 התראות והתערבות-אדם
- **[MVP]** התראה למשתמש כש: לקוח מגיב/מתלונן, חשבונית עוברת סף-הסלמה, או נדרש
  אישור לפני שליחה "חזקה".
- **[MVP]** **מצב-אישור (Approval mode):** המשתמש יכול לבחור "שלח אוטומטית" או
  "הצג-לי-לפני-שליחה" — קריטי לאמון בתחילת-הדרך.

## 4.7 ניהול-מחלוקות בסיסי
- **[MVP]** סימון חשבונית כ"במחלוקת" → עצירת-הרצף אוטומטית + התראה למשתמש (לא
  רודפים אחרי כסף שנוי-במחלוקת — שומר על יחסים ועל תאימות).
- **[V1+]** thread-מחלוקת מנוהל + תיעוד.

## 4.8 הגדרות וטון
- **[MVP]** בחירת **טון-מותג** (רשמי / ידידותי / נחרץ) ושפה (עברית/אנגלית).
- **[MVP]** חתימה, לוגו, ופרטי-קשר של העסק בכל הודעה.
- **[V1+]** "מצב-יחסים" פר-לקוח (עדין במיוחד / רגיל / נחרץ).

## 4.9 מטריצת-עדיפויות (MVP)

| חובה ל-MVP | דחוף-אבל-לא-עכשיו (V1) | מאוחר (V2) |
|-------------|-------------------------|-------------|
| ייבוא CSV/ידני | QuickBooks/Xero sync | תחזית-תזרים AI |
| רצף-AI באימייל | SMS/WhatsApp | פקטורינג/מקדמות |
| לינק-תשלום | בחירת-ערוץ אוטומטית | מולטי-משתמש/הרשאות |
| Aging + דוח-השפעה | רצפים פר-סגמנט | API ציבורי |
| Approval mode | success-fee billing אוטומטי | white-label לרו"ח |
