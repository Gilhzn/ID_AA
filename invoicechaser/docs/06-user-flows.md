# 06 · זרימות משתמש (User Flows)

זרימות מסך-אחר-מסך לתרחישים מרכזיים, כולל states ו-edge cases. מסומן MVP אלא אם צוין.

## 6.1 Onboarding + ייבוא ראשון

```
[הרשמה: אימייל/Google SSO] → [הגדרת-עסק: שם, לוגו, טון-מותג, שפה]
   → [חיבור-שליחה: אימות דומיין-אימייל / reply-to]
   → [ייבוא חשבוניות: העלאת CSV  או  הזנה ידנית]   (V1: חיבור QuickBooks/Xero)
   → [מיפוי-שדות אוטומטי + אישור] → [Dashboard עם aging report]
```
- **States:** טיוטה · מאומת · מוכן-לשליחה.
- **Edge cases:** CSV עם עמודות חסרות → אשף-מיפוי; אימייל לא-מאומת → fallback
  לשליחה דרך הדומיין שלנו עם reply-to של המשתמש.

## 6.2 הגדרת-רצף (Cadence) ואישור ראשוני

```
[בחירת cadence: ברירת-מחדל חכמה  או  התאמה אישית (+0/+7/+14/+30)]
   → [בחירת מצב: "שלח אוטומטית"  או  "אשר-לי-לפני-כל-שליחה" (Approval mode)]
   → [תצוגה-מקדימה של הודעות-AI לדוגמה] → [אישור והפעלה]
```
- **Edge case:** משתמש חושש → ברירת-המחדל היא Approval mode עד שנבנה אמון.

## 6.3 הרצף הרץ — שליחה ומעקב

```
[המנוע מזהה חשבוניות-פתוחות] → [AI מנסח הודעה מותאמת] →
   ├─ Approval mode → [המשתמש מאשר/עורך] → [שליחה]
   └─ Auto mode → [שליחה בתזמון האופטימלי]
→ [מעקב: נפתח? נלחץ? שולם?] → [עדכון סטטוס ב-Dashboard]
```
- **States לכל חשבונית:** פתוח · תזכורת-1/2/3 נשלחה · נצפה · במחלוקת · שולם · הסלמה.

## 6.4 קבלת-תשלום

```
[לקוח לוחץ לינק-תשלום בתזכורת] → [דף-תשלום (Stripe)] → [תשלום] →
   [webhook → סימון "שולם" אוטומטי] → [עצירת-רצף] → [עדכון דוח-השפעה]
```
- **Edge cases:** תשלום-חלקי (V1) → עדכון יתרה + המשך-רצף על היתרה; תשלום
  מחוץ-למערכת (העברה בנקאית) → המשתמש מסמן "שולם" ידנית (או זיהוי דרך QuickBooks).

## 6.5 תגובת-לקוח / מחלוקת

```
[לקוח עונה למייל / מסמן בעיה] → [המנוע עוצר-רצף אוטומטית] →
   [התראה למשתמש] → [המשתמש: סמן "במחלוקת" / השב / חדש-רצף]
```
- **Edge cases:** "כבר שילמתי" → בקשת-אימות מול הסטטוס; טון-תלונה → דגל-רגישות.

## 6.6 דוח-השפעה (ההוכחה + בסיס ה-success-fee)

```
[Dashboard → דוח-השפעה] → [כמה נגבה דרך המערכת · DSO לפני/אחרי ·
   זמן-ממוצע-עד-תשלום · כמה חשבוניות נסגרו] → [בסיס לחיוב success-fee]
```

## 6.7 מצבי-קצה גלובליים
- **חשבונית שבוטלה/זוכתה:** עצירת-רצף + הסרה מ-aging.
- **לקוח שביקש "להפסיק לפנות אליי" (opt-out):** עצירה מיידית + תיעוד (תאימות).
- **כשל-ספק-שליחה/תשלום:** retry + התראה שקופה.
- **מחיקת-חשבון:** ייצוא-נתונים + מחיקה (GDPR), שמירת-מינימום לחשבוניות-פעילות.
