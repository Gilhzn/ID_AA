# 04 · חיבור עסקים והדרכה (Onboarding & Training)

מדריך מעשי: איך מחברים סוכנות/עסק למערכת, ואיך מדריכים אותם להשתמש. נשען על
המנוע ב-[`../core`](../core/) ועל ה-playbook ב-[`01-offer-and-playbook.md`](01-offer-and-playbook.md).

---

## שני מודלי-הפעלה

| מודל | מי מריץ | מתי | יתרון |
|------|---------|-----|--------|
| **A. Done-for-you (Concierge)** | **אתה** מריץ; הסוכנות רק שולחת CSV ומאשרת | 3–10 הלקוחות הראשונים | אפס חיכוך ללקוח; אתה לומד את המוצר; success-fee קל |
| **B. Self-serve** | הסוכנות מריצה את הדשבורד בעצמה | אחרי שהוכחת ערך / בקנה-מידה | פחות עבודה ידנית שלך; מנוי |

**התחל ב-A.** זה הכי מהיר לכסף ולמידה. עבור ל-B כשיש לך 5+ לקוחות.

## חיבור עסק — 7 צעדים (מודל A)

### צעד 1 — שיחת-גילוי (15 דק')
שאל: כמה כסף תקוע אצלם בחשבוניות פתוחות? מה ה-DSO (ימים-ממוצע-עד-תשלום)? איך הם
גובים היום? מי הלקוחות שמאחרים? → זה גם ממפה כאב וגם מכין את ה"ניתוח חינם".

### צעד 2 — קבלת הנתונים (CSV)
בקש **ייצוא חשבוניות פתוחות** מתוכנת-החשבונות שלהם. כל התוכנות מייצאות ל-CSV/Excel:
- **QuickBooks:** Reports → Open Invoices → Export to CSV.
- **Xero:** Business → Invoices → Export.
- **חשבונית ירוקה / iCount / Rivhit:** דוח חשבוניות פתוחות → ייצוא Excel.

**פורמט ה-CSV שהמערכת קוראת** (כותרות בשורה הראשונה):
```
id,customerName,customerEmail,amount,currency,issueDate,dueDate,status,lang
INV-1042,מאיה לוי,maya@client.com,18000,ILS,2026-04-01,2026-05-01,open,he
```
- `status`: `open` / `paid` / `disputed`
- `lang`: `he` / `en` (שפת התזכורת ללקוח)
- תאריכים: `YYYY-MM-DD`
> אם לעסק יש כותרות שונות — ממפים ידנית פעם אחת לפני הייבוא (או ב-Self-serve דרך אשף-המיפוי).

### צעד 3 — "ניתוח-גבייה חינם" (הנשק)
```bash
cd invoicechaser/core
node src/report-cli.mjs <שם-הקובץ>.csv report-<עסק>.html
```
שלח את ה-HTML שנוצר. זה מראה כמה כסף תקוע, כמה באיחור, ואיזה תזכורות המערכת תשלח —
**ערך מיידי לפני שביקשת שקל.**

### צעד 4 — הקמת ה-Workspace + מיתוג
```bash
node src/operator-cli.mjs import <עסק>.json <קובץ>.csv \
  --name="שם הסוכנות" --signer="שם החותם" --reply="billing@agency.co.il"
```
(שם, חותם ו-reply-to מופיעים בכל תזכורת — חשוב שזה ייראה כמו הסוכנות, לא "רובוט".)

### צעד 5 — בחירת מצב (קריטי לאמון)
- **התחל ב-`--mode=approval`** — אתה/הסוכנות מאשרים כל הודעה לפני שליחה. זה בונה
  ביטחון שהטון מתאים מול הלקוחות שלהם.
- אחרי שבועיים שהכל תקין → אפשר `--mode=auto` (אבל "הודעה אחרונה" תמיד תדרוש אישור).

### צעד 6 — שגרת-יום (5 דק')
```bash
# מה צריך לצאת היום:
node src/operator-cli.mjs outbox <עסק>.json --out=./outbox-<תאריך>
#   → סקור את ה-.eml/index.md, אשר, ושלח (ידנית מ-Gmail, או --live עם Resend)
node src/operator-cli.mjs send <עסק>.json --live --yes        # אם מחובר Resend
#   או, אם שלחת ידנית:
node src/operator-cli.mjs sent-all <עסק>.json

# כשמגיע תשלום (מהבנק/אישור הסוכנות):
node src/operator-cli.mjs pay <עסק>.json INV-1043 42000 --at=2026-06-04
# אם לקוח התווכח על חשבונית:
node src/operator-cli.mjs dispute <עסק>.json INV-1046
```

### צעד 7 — שבועי/חודשי: הוכחה וחיוב
```bash
node src/operator-cli.mjs impact <עסק>.json          # DSO↓, כמה נגבה — שלח לסוכנות
node src/operator-cli.mjs bill   <עסק>.json --rate=12 --from=2026-06-01 --to=2026-06-30 --out=bill.html
```
שלח את `impact` (ההוכחה) ואת `bill.html` (החיוב). גובים רק על "מזכה" — חשבוניות
שהיו באיחור, נרדפו, ואז שולמו.

## מודל B — הדרכת עסק לשימוש-עצמי (Self-serve)

תן להם להריץ את הדשבורד:
```bash
cd invoicechaser/core
node src/server.mjs <עסק>.json --port=3000   # → http://localhost:3000
```

**סקריפט הדרכה — 5 דקות:**
1. **"זה הלוח שלך"** — למעלה KPIs: כמה נגבה, כמה תקוע, ימים-עד-תשלום.
2. **"החשבוניות שלך"** — הטבלה עם צבעי-איחור. ירוק=בסדר, צהוב=מתקרב, אדום=באיחור.
3. **"ה-Outbox"** — "אלה התזכורות שה-AI הכין להיום. קרא, וכשזה בסדר — 'סמן כנשלח'."
4. **"כשמשלמים"** — לחץ 'שולם' על החשבונית. "במחלוקת" עוצר את הרדיפה מיד.
5. **"ייבוא"** — הדבק CSV חדש מהנהלת-החשבונות מתי שיש חשבוניות חדשות.
6. **"חיוב החודש"** — מראה את העמלה.

**הדגש להם 3 דברים:**
- המערכת **אדיבה** — היא לא "חברת-גבייה". היא שומרת על היחסים עם הלקוח.
- הם **בשליטה** — שום דבר לא נשלח בלי אישור (במצב approval).
- חשבונית **במחלוקת = עצירה מיידית**. לא רודפים אחרי כסף שנוי-במחלוקת.

## כללי-זהב לתאימות (לומר ללקוח ולשמור עליהם)
- שולחים בשם הסוכנות, על החובות **של הסוכנות עצמה** (first-party) — זה כלי, לא
  חברת-גביית-חובות. אף פעם לא שפת-איום.
- מכבדים בקשת-לקוח "להפסיק לפנות אליי" (opt-out) — מיד.
- חשבונית במחלוקת → עוצרים. ראו [`../docs/10-roadmap-risks-compliance.md`](../docs/10-roadmap-risks-compliance.md).
- לפני לקוחות אמיתיים בתשלום — בדיקה משפטית קצרה פר-תחום-שיפוט.
