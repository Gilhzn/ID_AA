# 06 · Trust Index — מדד האמינות

ה-Trust Index הוא הנכס המרכזי של Synergy OS — ציון 0–100 שמתרגם התנהגות-אמיתית
למוניטין כמותי, נייד ואכיף. בניגוד ל"כוכבים" (סובייקטיבי, ניתן-למשחק), ה-Trust
Index מבוסס על **אירועים מאומתים** שקרו בתוך הפלטפורמה.

## 6.1 עקרונות תכנון

1. **התנהגות, לא דעות.** הציון נבנה מאירועים מדידים (עמידה בזמן, מסירה מאומתת),
   לא רק מחוות-דעת.
2. **קשה למשחק.** רכיבים מאומתים-מערכת + זיהוי דפוסי-הונאה.
3. **נייד.** הציון שייך למשתמש ונישא כ-Trust Badge (ראו 6.6).
4. **שקוף ומסביר.** המשתמש רואה ממה מורכב הציון ואיך לשפר.
5. **דינמי.** משתנה עם כל עסקה; אירועים ישנים שוקלים פחות (decay).

## 6.2 רכיבי הציון ומשקלים

המשקלים מכוילים פר-מסלול; להלן ברירת-מחדל ל-Gig Track (סכום = 100%):

| רכיב | משקל | איך נמדד (מאומת-מערכת) |
|------|------|--------------------------|
| **Reliability / Punctuality** | 30% | Check-in בזמן, עמידה בדד-ליינים, אפס No-Show |
| **Quality** | 30% | ציון אימות-מסירה (AI Work Verification) + אישור-לקוח |
| **Completion** | 15% | % עסקאות שהסתיימו ללא ביטול/סכסוך |
| **Vibe / Collaboration** | 10% | משוב-תקשורת, responsiveness, היעדר דגלים |
| **Verified Audits** | 10% | אימות GitHub/Figma/תעודות חיצוניות |
| **Tenure & Volume** | 5% | ותק + נפח עסקאות (anti-new-account-gaming) |

> **הערה:** ב-PRD המקורי הופיעו אחוזים נמוכים (3%/3%/1%/1%) — אלה ככל הנראה
> ערכי-טיוטה. כאן הוצע מודל מנורמל ל-100% עם משקלים בעלי-משמעות סטטיסטית.

## 6.3 נוסחת חישוב (מושגית)

```
TrustIndex = Σ (weightᵢ × scoreᵢ × decay(t)) × penaltyMultiplier
```
- `scoreᵢ` ∈ [0,1] לכל רכיב.
- `decay(t)` — אירוע ישן שוקל פחות (חצי-חיים ~12 חודשים) → הציון משקף ביצועים עכשוויים.
- `penaltyMultiplier` — מקדם-עונש על אירועים חמורים (No-Show, סכסוך-שהפסיד,
  הונאה) שמוריד את הציון מהר ומתאושש לאט.
- **Cold start:** משתמש חדש מקבל seed מבוסס-Onboarding-Audit (אימות חיצוני) +
  טווח-אמון מוגבל עד שייצבר היסטוריה אמיתית.

## 6.4 שימושים בציון (למה הוא חשוב)
- **דירוג Matching** — ציון גבוה = חשיפה טובה יותר.
- **תמחור-סיכון** — ציון נמוך = דרישת פיקדון/Escrow גבוה יותר; ציון גבוה = תנאי-מימון
  טובים יותר (מקדמות).
- **גישה ל-tiers** — מסלול Equity/עסקאות גדולות נפתח מעל סף-ציון.
- **תמחור פרמיות-ביטוח** — בסיס לתמחור מוצר ערבות-העסקה (ראו פרק 09).

## 6.5 Anti-Gaming (הגנה מפני מניפולציה)
- רכיבים מבוססי-מערכת (לא רק משוב) שאי-אפשר לזייף.
- זיהוי collusion (חשבונות שמדרגים זה את זה / עסקאות-דמה).
- משקל-נמוך לחשבונות חדשים/נפח-נמוך; אימות זהות חוסם sock-puppets.
- ביקורת-אנומליות: קפיצות-ציון חריגות → סקירה.

## 6.6 The Trust Badge — תג האמינות (מנוע הצמיחה)

תרגום הציון ל**נכס שיווקי נייד**:
- **תצוגה:** `"משתמש מאומת ב-Synergy OS · ציון אמינות 97"` — באנר/Badge עם קישור
  לפרופיל המאומת.
- **הטמעה (Embeddable):** קוד להטמעה ב-LinkedIn, אתר אישי, חתימת-מייל, הצעת-מחיר.
- **לולאת ויראליות:** כל Badge מוצג חיצונית = פרסומת חינמית + הוכחה-חברתית →
  משתמשים חדשים → עוד Badges. זהו ערוץ-ההפצה הזול ביותר של המוצר.
- **תקן פתוח (חזון):** Trust Badge כפרוטוקול-אמון שפלטפורמות אחרות יכולות לאמת
  (גשר ל-Trust-as-a-Service).

## 6.7 פרטיות ואתיקה
- המשתמש שולט מה ציבורי (ציון/Badge) ומה פרטי (פירוט עסקאות).
- "זכות להסבר" — שקיפות מלאה על הרכב הציון.
- מנגנון-ערעור על אירוע שפגע בציון (למשל סכסוך שהוכרע בטעות).
- היזהרות מהטיה: ניטור הוגנות לפי קבוצות (ראו [פרק 12](12-roadmap-risks-compliance.md)).
