# 03 · פרסונות ו-Jobs-To-Be-Done

## 3.1 פרסונות מרכזיות

### P1 — "דניאל", הפרילנסר המקצועי (Talent · Gig Track)
- **מי:** מפתח/מעצב/PM עצמאי, 28–40, מנוסה, עובד מול 3–6 לקוחות בשנה.
- **כאב:** רודף אחרי תשלומים, נשרף מ-scope creep ו-Ghosting, מבזבז זמן על לקוחות
  לא רציניים, מתחיל "מאפס" בכל פלטפורמה כי המוניטין לא נייד.
- **רוצה:** לקוחות מסוננים ורציניים, תשלום מובטח ב-Escrow, scope ברור וחתום,
  ומוניטין שצובר ערך לאורך זמן ועובר איתו.
- **מדד הצלחה:** פחות זמן-מכירה, אפס חובות אבודים, יותר עבודות חוזרות.

### P2 — "מאיה", מייסדת/מנהלת בסטארטאפ (Client · Gig + Team Track)
- **מי:** מייסדת/VP בחברה צעירה, מגייסת טאלנט לפרויקטים, תקציב מוגבל, זמן אפסי.
- **כאב:** מתקשה לדעת למי לסמוך, נכוותה מספקים שנעלמו/סיפקו זבל, מפחדת לשלם מראש.
- **רוצה:** למצוא מהר טאלנט מאומת, להגדיר scope, לשלם רק על מסירה מאומתת, ולנהל
  הכל במקום אחד.
- **מדד הצלחה:** Time-to-hire קצר, מסירה בזמן ובאיכות, אפס "הפתעות".

### P3 — "יונתן", היזם מחפש-שותף (Founder · Equity Track)
- **מי:** יזם עם רעיון/חברה מוקדמת, מחפש co-founder טכני/עסקי.
- **כאב:** "נישואים עסקיים" עם זר; הפחד מ-co-founder שמקבל הון ועוזב / לא תורם;
  חלוקת מניות ו-vesting הם שדה-מוקשים משפטי.
- **רוצה:** למצוא שותף תואם, "להתארס" לפני "להתחתן", ולקשור הון לביצועים אמיתיים.
- **מדד הצלחה:** שותפות יציבה, vesting הוגן, פחות סיכון משפטי.

### P4 — "נועה", מנהלת סוכנות/סטודיו (Agency · Team Track)
- **מי:** מנהלת סוכנות 5–30 איש שמספקת פרויקטים שלמים ללקוחות.
- **כאב:** תזרים מזומנים (לקוחות משלמים מאוחר), אמון מול לקוחות חדשים, ניהול עסקאות.
- **רוצה:** עסקאות גדולות מאובטחות ב-Escrow, מקדמות/מימון, ומוניטין ארגוני שמושך
  לקוחות.
- **מדד הצלחה:** תזרים יציב, יותר עסקאות B2B, מותג-אמון ארגוני.

### P5 — "פלטפורמה שותפה" (B2B · Trust-as-a-Service)
- **מי:** marketplace/HR-tech אחר שרוצה לשלב אימות וציון-אמון מבלי לבנות.
- **רוצה:** API לאימות זהות, משיכת Trust Index ושיבוץ Trust Badge.

## 3.3 מסע משתמש ברמת-על (High-Level Journey)

```
גילוי → הרשמה + Onboarding Audit (AI מאמת זהות/ניסיון) →
קבלת Trust Index התחלתי → התאמה סמנטית (Matching) →
Progressive Disclosure (חשיפת פרטים בהדרגה) → הסכמה על scope + חוזה (AI) →
נעילת Escrow → עבודה לפי אבני-דרך → אימות מסירה (AI) → שחרור תשלום →
דירוג הדדי → עדכון Trust Index → Trust Badge מתעדכן → עבודה חוזרת
```
