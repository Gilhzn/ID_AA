# 12 · מפת דרכים, סיכונים ותאימות

## 12.1 מפת דרכים (Roadmap)

### Phase 0 — Validation (0–2 חודשים)
- ראיונות-בעיה עם 30+ פרילנסרים/לקוחות ב-Beachhead.
- "Concierge MVP": Escrow ידני (שותף-סליקה) ל-10–20 עסקאות אמיתיות → הוכחת-כאב
  ונכונות-לשלם **לפני** בניית-מוצר כבדה.

### Phase 1 — MVP (3–6 חודשים)
- **Gig Track, Fixed Price + Milestone Escrow בלבד.**
- Onboarding + Gatekeeper בסיסי, Matching v1, Workspace, Trust Index v1, Trust Badge.
- אינטגרציית GitHub/Figma לאימות-מסירה בסיסי. KYC + Stripe Connect.
- **יעד:** עשרות-מאות עסקאות מוצלחות; הוכחת North Star (Verified Completion Rate).

### Phase 2 — V1 (6–12 חודשים)
- Daily Rate + Micro-tasks; AI Contract Drafting ו-Work Verification מלאים.
- Dispute Mediation; SaaS tiers; Referral; הרחבת-ורטיקלים (Marketing/Growth).
- מוצרי-פיננסים ראשונים (מקדמות).

### Phase 3 — V2 (12–24 חודשים)
- **Equity & Venture Track** (אחרי ביסוס משפטי) + Agency/Team Track.
- Trust-as-a-Service API; ביטוח/ערבות-עסקה; הרחבה גלובלית.
- מובייל מלא; אנליטיקה מתקדמת.

## 12.2 KPIs ו-North Star
- **North Star:** Verified Successful Completion Rate (% עסקאות שהסתיימו במסירה
  מאומתת + תשלום משוחרר ללא סכסוך).
- **צמיחה:** GMV, משתמשים-פעילים, K-factor (Badge), CAC, NRR.
- **בריאות:** dispute-rate, No-Show rate, time-to-first-deal, אחזקה 30/90 יום.
- **כסף:** take-rate אפקטיבי, ARPU, LTV:CAC.

## 12.3 מטריצת סיכונים

| סיכון | חומרה | הסתברות | מיטיגציה |
|--------|--------|-----------|-----------|
| Cold start (תרנגול-ביצה) | גבוהה | גבוהה | Beachhead צר + supply-first + concierge |
| רגולציה (כסף/ני"ע) | **גבוהה** | בינונית | שותף-סליקה מורשה, ייעוץ-משפטי, השקת-Equity מאוחרת |
| Disintermediation (עוקפים את הפלטפורמה) | גבוהה | גבוהה | ערך-Escrow, Trust Badge, חיוב-מחוץ אסור, איכות-Workspace |
| חיקוי ע"י incumbents | בינונית | בינונית | מהירות, עומק גרף-אמון, מיצוב-פרימיום |
| תלות בשותף-סליקה | בינונית | בינונית | חוזה+backup, leverage מסחרי |
| הטיית-AI / החלטות-כסף שגויות | גבוהה | בינונית | human-in-the-loop, ערעור, ניטור-הוגנות |
| הונאה/abuse | בינונית | גבוהה | KYC, anti-gaming, fraud-monitoring |
| עומס-תפעולי בגישור | בינונית | בינונית | AI-first, בוררים-אנושיים מדורגים |

## 12.4 תאימות רגולטורית — קריטי

> **זהו סיכון-העל של המוצר. חובה ייעוץ-משפטי מומחה פר-תחום-שיפוט. הסעיפים להלן הם
> כיוון, לא ייעוץ משפטי.**

### תשלומים / Escrow
- אחזקת-כספי-צד-שלישי עלולה לדרוש רישוי (Money Transmitter בארה"ב פר-מדינה / EMI
  באיחוד / רישוי בישראל). **פתרון:** בנייה מעל שותף-סליקה מורשה (Stripe Connect /
  MangoPay) שמחזיק את הרישיון — אנו "פלטפורמה", לא "מעביר-כספים".
- **PCI-DSS** לטיפול-כרטיסים (דרך השותף). הפרדת-כספי-נאמנות.

### Equity Track — דיני ניירות-ערך
- הבטחת/הקצאת-הון נוגעת לדיני-ני"ע (SEC/רשות-ני"ע). **אנו לא מנפיקים ולא מייעצים**
  — אנו כלי-תיעוד-והסכמה שמפנה לתבניות מאושרות (SAFE/Founder Agreement) ולחתימה.
  השקה רק אחרי ביסוס-משפטי (Phase 3).

### KYC / AML
- אימות-זהות ומניעת הלבנת-הון; ניטור-עסקאות; דיווח לפי-חוק.

### עבודה / מיסוי / סיווג-עובדים
- סיווג קבלן-עצמאי מול עובד (סיכון misclassification); דיווחי-מס (1099/חשבוניות);
  בהמשך שילוב EOR לחוצה-גבולות.

### פרטיות
- GDPR/CCPA: מינימום-נתונים, הסכמה, זכות-מחיקה/ייצוא, data-residency, DPO.

### אחריות-פלטפורמה ו-AI
- מסמכי-משפט (תנאי-שימוש, הגבלת-אחריות), שקיפות-החלטות-AI, מנגנון-ערעור, ניטור-הטיה.

## 12.5 הנחות-יסוד שדורשות אימות
- שמשתמשים מוכנים לשלם פרמיה (take-rate) עבור אמון/Escrow.
- ש-AI Work Verification מדויק מספיק כדי להפחית סכסוכים בפועל.
- שה-Trust Badge מייצר ויראליות בעלת K-factor משמעותי.
- שעלות הרישוי/הציות ברת-ניהול בשלב מוקדם.
